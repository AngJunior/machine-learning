# 🧠 Fundamentos de Machine Learning e Deep Learning

Este repositório atua como um arquivo histórico do início da minha jornada em Ciência de Dados e Inteligência Artificial. Ele contém implementações de modelos fundamentais de regressão e classificação, consolidando a base teórica e prática necessária para a construção de arquiteturas mais complexas.

Atualmente, minha pesquisa em IA envolve **Deep Learning aplicado à engenharia**, especificamente o desenvolvimento de **Physics-Informed Neural Networks (PINNs)** em PyTorch para a resolução de equações de Navier-Stokes e predição de fluxo hemodinâmico.

### 📂 Projetos Incluídos

*   **`boston_housing_regression`**: Modelagem preditiva para estimativa de valores imobiliários. Demonstra o tratamento inicial de dados, normalização e aplicação de modelos de regressão multivariada para extração de padrões quantitativos.
*   **`binary_classifier_pytorch`**: Arquitetura inicial de uma Rede Neural Artificial (Multilayer Perceptron - MLP) construída do zero em PyTorch. Focada em separação não-linear de classes, backpropagation e entendimento de funções de perda e otimizadores.

### 🛠️ Tecnologias e Conceitos Aplicados
- **Linguagem:** Python
- **Bibliotecas:** PyTorch, Pandas, Scikit-learn
- **Conceitos:** Regressão, Classificação Binária, Funções de Ativação, Backpropagation, Preparação de Dados.
